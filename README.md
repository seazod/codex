# 小飞机弹弓闯关模拟（可视化界面）

这是一个基于 **Python + Tkinter** 的可视化小游戏，包含：

- 按简化空气动力学计算飞行（升力、阻力、重力）
- 使用弹弓发射，角度与力度可调
- 通关模式：按飞行距离奖励金币
- 金币升级：飞机与弹弓能力提升
- 多关卡与障碍物

## 运行

```bash
python3 plane_game.py
```

> 程序是 GUI 应用，启动后会弹出窗口；终端看起来“卡住”是正常现象（主循环在运行）。

## 无图形环境演示

```bash
python3 plane_game.py --demo
```

## macOS 常见问题

如果执行后“没有反应”，请按下面排查：

1. 先看终端是否打印：`正在启动可视化窗口...`。
2. 确认窗口没有被挡在后台（程序会尝试置顶）。
3. 用 `python3 plane_game.py --demo` 验证程序本体是否可运行。
4. 若 GUI 报 `TclError`，说明当前 Python/Tk 图形环境不可用，需要安装/启用 Tk 支持的 Python 发行版。

## 操作说明

- 左下控制面板可设置发射角度、弹弓力度、飞行俯仰控制。
- 点击 **发射** 开始本关。
- 飞行中可调节“俯仰控制”来控制升力变化。
- 使用金币可点击按钮升级飞机/弹弓。
- 过关后自动进入下一关；全部完成后会提示通关。
