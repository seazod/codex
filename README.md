# 小飞机弹弓闯关模拟（可视化界面）

这是一个基于 **Python + Tkinter** 的可视化小游戏，包含：

- 按简化空气动力学计算飞行（升力、阻力、重力）
- 使用弹弓发射，角度与力度可调
- 通关模式：按飞行距离奖励金币
- 金币升级：飞机与弹弓能力提升
- 多关卡与障碍物

## 运行

```bash
python3 plane_game.py
```

## 操作说明

- 左下控制面板可设置发射角度、弹弓力度、飞行俯仰控制。
- 点击 **发射** 开始本关。
- 飞行中可调节“俯仰控制”来控制升力变化。
- 使用金币可点击按钮升级飞机/弹弓。
- 过关后自动进入下一关；全部完成后会提示通关。
